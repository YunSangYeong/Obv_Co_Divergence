# OBV + CO DUAL DIVERGENCE V1.0

Bybit USDT 무기한 선물의 15분봉에서 OBV와 Chaikin Oscillator가 **동일한 가격 피벗**에 대해 함께 나타내는 일반 다이버전스를 찾는 독립형 정적 웹 앱입니다. 자동매매 기능은 없습니다. API 키·로그인·DB·백엔드가 필요하지 않습니다.

## 실행

Node.js 24 권장 (Vite 요구 버전: 20.19+ 또는 22.12+).

```sh
npm ci
npm test
npm run dev
```

프로덕션: `npm run build`, 로컬 빌드 확인: `npm run preview`.

```sh
npx playwright install chromium
npm run build
npm run test:ui
# 시스템 Chromium을 사용하는 경우
CHROMIUM_PATH=/usr/bin/chromium npm run test:ui
```

페이지 접속만으로 검색하지 않습니다. 방향을 선택하고 **검색 시작**을 누르세요. 검색 취소 후 재검색할 수 있습니다. 검색 중 중복 실행은 차단합니다. 이전 신호는 카드의 펼치기 메뉴에서 확인할 수 있습니다. 종목명 또는 TradingView 링크는 새 탭에서 차트를 엽니다.

## 탐지 규칙

- instruments-info 전체 페이지를 수집·중복 제거합니다. quoteCoin/settleCoin=USDT, contractType=LinearPerpetual, status=Trading만 사용합니다.
- 이번 검색의 tickers.turnover24h ≥ 10,000,000 USDT인 **모든** 종목을 분석합니다. 종목 수 상한은 없습니다. 시세 누락은 실패 사유에 따로 남깁니다.
- 서버 시각을 검색 시작 기준으로 고정합니다. 실패하면 시스템 시각을 사용하고 경고합니다. 캔들 요청에 확정 봉 종료 시각을 지정하며, 수신 후에도 미확정 봉을 제거합니다. UTC로 계산하고 KST로 표시합니다.
- 500봉을 요청합니다. 최소 확정 200봉, 연속 15분 간격, 마지막 확정 봉 존재, OHLC 관계·거래량·숫자·중복 충돌을 검증합니다. 데이터 부족/비정상 종목은 실패·제외 사유를 표시합니다.
- OBV: 최초 0, 종가 상승/하락에 따라 현재 base volume 가감, 동일 종가 유지.
- ADL: 최초 누적값 0에서 MFV 합산. High=Low는 MFM=0. CO=EMA(ADL,3)−EMA(ADL,10). EMA는 첫 ADL을 시드로 재귀 계산합니다. 첫 100봉의 피벗은 워밍업으로 제외합니다.
- 가격 low/high 피벗 좌 5 / 우 5. 같은 극값은 전체 11봉 창에서 **가장 오른쪽**을 채택합니다. 오른쪽 확인 봉이 마감되어야 확정됩니다.
- 동일 종류의 연속된 최신 피벗 두 개만 비교합니다. 실패한 비교도 최신 피벗으로 갱신합니다. 간격 5–80봉(양 끝 포함).
- LONG: 가격 저점 하락, 해당 시점 OBV·CO 모두 상승. SHORT: 가격 고점 상승, OBV·CO 모두 하락. 지표 자체 피벗을 별도로 매칭하지 않습니다.
- 발생 시각은 두 번째 피벗 봉 **시작** 시각, 확정 시각은 우측 5번째 봉 **마감** 시각입니다. 최근 10개 확정 봉에 속하는 확인 봉만 선택합니다. 경과 봉 0–9.
- 추가 추세/RSI/ADX 필터는 없습니다. 신호는 확정 시각 내림차순, 같은 시각이면 거래대금 내림차순입니다.

## API·캐시·오류 정책

공식 `https://api.bybit.com/v5/market/`만 사용합니다. 기본 동시 요청 5개, 작업 간 120ms 간격, 요청 타임아웃 12초입니다. HTTP 429/5xx, retCode 10006, 네트워크 오류를 최대 3회 시도합니다. 재시도 대기 1초/2초 + 0–500ms 지터를 사용합니다. 모든 응답의 retCode와 필수 구조를 검증합니다.

캔들만 메모리에 최대 60초 재사용합니다. 같은 마지막 확정 봉인 경우만 캐시를 사용합니다. 서버 시간·종목 목록·시세는 매 검색 새로 조회합니다. 기준 시각과 캐시 사용 종목 수를 표시합니다. 실시간 가격은 tickers 스냅샷이며 스트리밍 가격이 아닙니다.

API 요청 횟수는 재시도와 서버 시간 요청까지 포함합니다. 정상 분석·실패·전체 대상 수를 분리합니다. 취소·일부 실패·치명적 오류는 정상 완료와 구분합니다. 실패가 있는 검색의 신호는 전체 시장의 완전한 결과가 아닙니다. 일부 실패 때 결과가 없어도 정상 0건으로 확정하지 않습니다.

브라우저 fetch 실패만으로 CORS·연결 장애를 구분할 수 없으므로 추정 원인을 안내합니다. 외부 프록시는 사용하지 않습니다. Bybit 지역 제한, CORS 정책, 사용자 네트워크 정책이 있으면 사용이 제한될 수 있습니다.

TradingView의 `BYBIT:<USDT 심볼>.P` 네임스페이스와 `interval=15`를 사용합니다. 허용된 심볼 문자만 변환하며 그 외에는 Bybit 링크만 제공합니다. **개별 종목의 TradingView 등록 여부는 미검증**입니다. 정적 브라우저에서 외부 차트의 종목 미지원 상태를 자동 감지할 수 없어 모든 카드에 Bybit 거래 화면 대안을 제공합니다. URL 인코딩 및 noopener/noreferrer를 적용했습니다.

## 구조

- `src/api/bybit.js`: 공식 API, 페이지 순회, 재시도·취소, 데이터 정제
- `src/indicators/`: OBV, CO/EMA, 가격 피벗, 이중 다이버전스
- `src/scanner/scanner.js`: 전체 대상 선정, 병렬 작업, 캐시, 집계
- `src/main.js`, `src/style.css`: 한국어 모바일 우선 UI
- `tests/core.test.js`: 지표·시간·피벗·API·스캐너 테스트
- `tests/ui/mobile.spec.js`: Chromium 모바일 뷰포트, 모의 API UI, Pages 하위 경로 검증

## GitHub Pages 배포

1. 변경 파일을 `YunSangYeong/Obv_Co_Divergence`의 `main`에 커밋·푸시합니다.
2. GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다.
3. `Test and deploy Pages` 워크플로를 실행합니다. 테스트 후 dist를 Pages에 배포합니다.
4. 배포된 페이지에서 Android Chrome으로 검색을 실행해 실제 API/CORS 접근을 확인하세요.

Vite `base: './'`로 `/Obv_Co_Divergence/` 등 하위 경로를 지원합니다. 클라이언트 라우터가 없어 기본 페이지 새로고침에 별도 fallback이 필요하지 않습니다. 배포 뒤 빈 화면이면 Actions 산출물과 브라우저의 asset 404를 확인하세요. 저장소의 소스 index.html을 직접 열지 말고 Vite 또는 빌드한 dist를 사용해야 합니다.

## 검증 기록과 제한

2026-11-02 개발 환경에서:

- 단위·통합 테스트 16개 통과. LONG/SHORT, 지표 한 개만 충족, 미확정 피벗, 워밍업, 최근 10봉 경계, 간격 경계, 동일 가격 타이브레이크, 진행 봉 제거, 순서·중복·비정상 데이터, 페이지 순회, 재시도, 취소·중복 방지, 상한 없는 103종목 모의 분석·캐시를 검증했습니다.
- 프로덕션 Vite 빌드 통과.
- 시스템 Chromium 390×844 모바일 에뮬레이션 테스트 4개 통과. 초기 자동 요청 없음, 방향 선택, 오류, 취소, 실제 계산 파이프라인을 통한 모의 LONG 카드, 가로 넘침 없음, 빌드 산출물 하위 경로 로드·새로고침을 검증했습니다. 화면 캡처도 확인했습니다. **모의 데이터는 테스트 파일에서만 사용하며 앱에 포함하지 않습니다.**
- 실제 Android 기기, 실시간 Bybit 검색, 개별 TradingView 지원, GitHub Pages 원격 배포: **미검증**.
- 실제 Bybit 접근 시 클라우드 egress 프록시가 CONNECT HTTP 403을 반환했습니다. API 원본 서버 응답이나 브라우저 CORS 판정이 아닙니다. 환경 설정 초안에 api.bybit.com 허용을 저장했으나 적용·게시와 실제 재검증은 별개입니다.
